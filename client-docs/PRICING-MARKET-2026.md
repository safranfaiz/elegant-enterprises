# Market pricing — 6-page static business website (Sri Lanka)

**Project:** Elegant Enterprises v2  
**Survey date:** November 2026  
**Scope:** Custom responsive static site (~6 pages), contact/maps/WhatsApp, basic SEO, domain + hosting setup + deployment (similar to this repo).

## Adjustments for *this* project

Compared with a 5-page template package:

| Factor | Effect on price |
|--------|-----------------|
| **6th page** (Factory) | +LKR 5,000 – 12,000 |
| **Hand-coded premium UI** (custom CSS, animations) | +LKR 25,000 – 55,000 vs cheapest packages |
| **Domain + hosting + deployment labour** | +LKR 15,000 – 35,000 (when not bundled free for 1 year) |
| **Fast delivery (4–7 Nov)** | Optional +5–10% |

## Recurring costs (client, annual — not on build invoice)

- Domain: ~LKR 4,000 – 6,500/yr  
- Hosting: ~LKR 12,000 – 45,000/yr (brochure sites)  
- Maintenance: ~LKR 36,000+/yr if offered separately
